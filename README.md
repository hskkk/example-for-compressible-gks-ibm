# example-for-compressible-gks-ibm
ma7-inflow-4-sphere

The execution environment of EUM.exe is based on Ubuntu 22.04 LTS and NVIDIA HPC SDK 23.3 (NVHPC 23.3). 
The program is compiled using the NVHPC compiler suite with CUDA-enabled Fortran support.

The output files are stored in the OUTPUT directory. 
The Fluid folder contains the flow-field distribution data, while the Part folder contains the solid-particle distribution data.
All output files are generated in Tecplot-compatible formats and can be directly visualized using Tecplot.
